# 怎么用 AI 工具做出一个 WEB 版宏观经济分析报告

![封面](imgs/cover.png)

## 00 前言

上次完成了2025年第四季度的 Web 版宏观经济分析报告，从数据分析、内容收集、前端实现，全程在 AI 工具加持下完成。这篇文章记录工具选型、**Agent Skills** 用法和完整 **AI 工作流**。

**本文内容：**
- **01 工具全景**：四类 AI 工具的定位与选型
- **02 工作流框架**：核心逻辑、复用性与数据安全
- **03 完整工作流**：六步从数据到报告上线

## 01 工具全景

| 类型 | 代表工具 | 定位 |
|---|---|---|
| **对话类** | Claude / ChatGPT / Gemini | 自然语言问答，查资料入口 |
| **知识管理类** | NotebookLM | 基于上传文档回答，有来源 |
| **原型生成类** | Google AI Studio / Bolt.new | 描述需求直接生成可运行应用 |
| **AI IDE 类** | Claude Code / Cursor / Windsurf | 读项目文件、运行代码、真正帮你写代码 |

本次报告主要使用 **NotebookLM + Google AI Studio + Claude Code** 三类工具串联：NotebookLM 负责内容检索，AI Studio 负责原型生成，Claude Code 负责本地迭代。

## 02 工作流框架

核心逻辑：**专业工具分段负责，Agent Skill 在关键节点注入专业规范**。

| 层次 | 工具 | 职责 |
|---|---|---|
| **内容层** | NotebookLM | 大规模文档检索 + 结构化内容生产 |
| **原型层** | Google AI Studio | 免费快速生成可运行前端框架 |
| **实现层** | Claude Code | 本地精细迭代、填充内容、部署 |

### 复用性

框架不变，工具不变，Skill 不变，只换内容——换数据集、换行业、换历史报告即可直接复用。

### 数据安全

使用第三方在线服务前，**必须先判断数据敏感程度**：

- **适合**：政府公开统计数据、公开发布的分析文章、已脱敏数据集
- **不适合**：公司内部财务/客户数据、个人隐私信息、竞争敏感信息

内部敏感数据需替换为本地部署方案或使用签有数据安全协议的企业版服务。

## 03 完整工作流：六步从数据到报告上线

| 步骤 | 工具 | 做什么 | 输出 |
|---|---|---|---|
| Step 1 | Claude Code | 读取 7 篇历史报告，提炼编写指南 | 报告框架 + 写作规范 |
| Step 2 | NotebookLM | 上传 105 篇参考文章，注入编写指南 | 可跨文档检索的知识库 |
| Step 3 | NotebookLM + Agent Skill | 按章节逐一提问，生产内容初稿 | 各章节结构化初稿 |
| Step 4 | Google AI Studio | 用提示词生成前端框架 | 可运行的 React 项目模板 |
| Step 5 | Claude Code + Agent Skill | 填充内容、迭代样式、拆分组件 | 完整代码库（33 组件 + 27 数据文件）|
| Step 6 | 腾讯云 | 部署上线 | 40 张幻灯片的在线演示系统 |

### Step 1：提炼编写指南

用 Claude Code 读取 7 篇历史报告，提炼出包含分析框架和写作规范的指南文档。关键规则：**「标题即结论」**——每页 PPT 标题直接写核心判断，而非章节描述。

### Step 2：NotebookLM 构建知识库

上传 105 篇宏观经济解读文章，将 Step 1 的编写指南注入 NotebookLM 的系统提示词，使每次提问都自动遵循专业框架。

### Step 3：生产内容初稿 + Agent Skills

#### 按章节提问

按章节逐一提问（如「请整理出 GDP 章节的内容」），NotebookLM 产出已按专业报告格式组织好的各章节初稿，可直接进入后续流程。

#### Agent Skills：让 AI 变专业

Agent Skills 是给 AI 安装「专业技能包」的开放标准。每个 Skill 是一个文件夹，含 `SKILL.md` 写清楚 AI 在该场景下的思考方式、方法和输出格式，安装一次、对整个项目持续生效。

Anthropic 于 2025 年 12 月发布这一开放标准，OpenAI Codex、Cursor、GitHub、Microsoft 均已集成。推荐平台：[skills.sh](https://skills.sh)——支持 Claude Code、Cursor、GitHub Copilot 一键配置。

#### 安装前后对比

Excel 数据：国家统计局 GDP 季度数据，2020Q1—2025Q4，24 个季度、74 个指标。同一提示词、同一数据，安装统计分析 Skill 前后对比：

```bash
npx skills add anthropics/knowledge-work-plugins --skill statistical-analysis
```

**安装前**：结构完整，但停留在描述层面——异常值未识别、价格分析只有年度均值、区域分析只有规模排名、结论缺乏数据支撑。

**安装后**：
- 用 IQR 法识别统计极值，剔除异常后真实增速中枢约 **4.7%**
- 逐季量化通缩：标注启动点（2023Q2）、最深点（2025Q2，-1.3%）、收窄趋势
- 建筑业增速首次转负到持续恶化的完整风险路径一目了然

| 评价维度 | 权重 | 安装前 | 安装后 |
|---|---|---|---|
| 统计分析方法 | 25% | 6.0 | 9.5 |
| 洞察深度 | 20% | 7.0 | 9.0 |
| 数据覆盖完整性 | 15% | 7.5 | 9.0 |
| 风险识别质量 | 10% | 7.5 | 9.0 |
| 结构逻辑 | 10% | 8.5 | 8.5 |
| 可读性与传播性 | 10% | 9.0 | 7.0 |
| 前瞻性与实用价值 | 10% | 7.0 | 8.5 |
| **加权总分** | **100%** | **7.40** | **8.90** |

### Step 4：Google AI Studio 生成前端框架

选 Google AI Studio 的原因：**免费 + Gemini 3 Pro，前端效果出色**。模板阶段反复调风格，用 AI Studio 把框架定好再交给 Claude Code 填充，省去大量 token 消耗。

提示词要点：用「麦肯锡风格」作视觉锚点、列明页面类型清单、指定内容页具体布局比例、提前声明「图表自适应不出现滚动条」约束。

### Step 5：AI Coding + Agent Skill 迭代

先安装 React 最佳实践 Skill：

```bash
npx skills add vercel-labs/agent-skills --skill vercel-react-best-practices
```

再用自然语言驱动迭代：「把 Step 3 整理的报告内容填入对应幻灯片」。

**两个关键做法：**

1. **抽取基础组件**（`BaseContentSlide`、`BaseCard`、`BaseLineChart`、`BaseTable` 等）——三人分别用 Claude Code、Cursor、Trae 协作时，视觉一致性由组件自身保证，不依赖 AI 的「记忆」或口头约定

2. **每页一个独立 `.tsx` 文件**——对人：按页码直接定位文件；对 AI：`@ContentSlide05.tsx` 精准上下文，避免扫描整个项目消耗 token

最终：33 个组件文件 + 27 个数据文件，约 7000 行代码。

### Step 6：部署上线

部署到腾讯云，40 张幻灯片，16:9 自适应，支持滚轮和键盘切换。结构：封面 + 目录 + 8 个分析章节 + 结束页，每章节含过渡页衔接。

## 总结

**专业工具分段负责，Agent Skill 在关键节点注入专业规范**——这是这套工作流的核心逻辑，也是它可以跨场景复用的原因。

- 换数据集、换行业、换历史报告，框架和工具不变，只换内容
- 使用第三方工具前确认数据来自公开渠道
- Agent Skills 就是新时代的 App——写一次、到处用、社区共享，不需要懂 Prompt 工程

### 待改进方向

- **数据采集自动化**：用爬虫/RSS 自动抓取，对接 NotebookLM API，减少手动搬运
- **多格式导出**：CI/CD 加 Puppeteer 截图转 PDF，或用 `pptx` skill 同步输出演示文稿
- **定制 Skill**：为宏观经济场景维护领域专用 Skill，涵盖季节调整、基数效应修正等专有处理方式
