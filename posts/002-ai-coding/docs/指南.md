# 附录：宏观经济分析PPT编写指南

本指南旨在规范宏观经济分析报告的编写思路、章节安排、数据选取及分析逻辑。

## 一、 核心编写思路

宏观经济分析报告的核心逻辑遵循 **“宏观总览 -> 供需拆解 -> 政策与效应 -> 金融印证”** 的闭环结构。

1.  **由总到分**：先看 GDP 总量与价格水平，定调经济所处周期（如：复苏、通缩、企稳）；再拆解到产业、行业和具体驱动力（三驾马车）。
2.  **量价结合**：不仅关注实际增长（量），高度关注价格指标（平减指数、CPI、PPI），以此判断企业盈利空间和宏观温差（名义 GDP vs 实际 GDP）。
3.  **政策归因**：数据波动需结合当期核心政策（如“两新两重”、“反内卷”、“以旧换新”）进行解释，评估政策落地的有效性。
4.  **虚实印证**：实体经济数据（生产、消费、投资）需与金融数据（社融、信贷、M1/M2）相互印证，判断资金是否进入实体以及市场信心。

## 二、 报告标准目录架构

一份标准的宏观经济分析 PPT 应包含以下两大核心板块：

### 第一部分：宏观层经济数据
1.  **GDP**：增长态势与结构分析
2.  **生产**：工业增加值、PMI、企业效益
3.  **消费**：社零总额、服务零售、居民收支与就业
4.  **投资**：固投总量、三大支柱（基建、制造、地产）
5.  **进出口**：贸易总额、国别结构、产品结构
6.  **财政**：收支情况、土地出让金

### 第二部分：金融层数据
1.  **货币供需**：M1、M2、剪刀差
2.  **信贷与存款**：社融增量、人民币贷款结构（居民/企业）、存款流向

## 三、 分章节写作章法与关键指标

### 1. GDP 分析：定基调，找温差
*   **核心图表**：GDP 现价/不变价当季同比、三产业拉动百分点、三产业平减指数。
*   **写作重点**：
    *   **名义 vs 实际**：对比名义 GDP 与实际 GDP 增速，判断是否存在“增量不增收”或通缩压力。
    *   **结构贡献**：分析第一、二、三产业的拉动率变化，指出主要拖累项（如房地产对第二产业的拖累）或支撑项（如服务业的复苏）。
    *   **价格传导**：通过平减指数分析上中下游的价格传递情况。

### 2. 生产端分析：看景气，看利润
*   **工业增加值**：关注“高技术制造业”与“整体规上工业”的增速差，体现新旧动能转换。
*   **PMI**：
    *   **荣枯线**：判断制造业是否处于扩张区间。
    *   **供需关系**：对比“生产指数”与“新订单指数”，判断是否存在“生产强、需求弱”的供需错配。
    *   **规模分化**：关注大、中、小型企业的 PMI 分化，评估中小企业生存状况。
*   **PPI**：关注生产资料（上游成本）与生活资料（下游售价）的传导，以及重点行业（如煤炭、钢铁、锂电）的价格波动对利润的影响。
*   **企业效益**：关注“营收增速”与“利润增速”的背离（增收不增利），分析成本、费用和投资收益对利润的贡献。

### 3. 消费分析：看意愿，看结构
*   **社零总额**：
    *   **商品 vs 服务**：区分商品零售与餐饮/服务零售的增速差异，判断服务消费是否强于实物消费。
    *   **品类分析**：重点关注大宗消费（汽车、家电-受以旧换新政策影响）与必选消费（粮油食品）的分化。
    *   **城市分化**：对比北上广深与全国增速，分析一线城市的消费降级或存量特征。
*   **CPI**：
    *   **核心 CPI**：剔除食品能源后的核心 CPI 是判断内需是否疲软的关键。
    *   **猪周期与鲜菜**：解释 CPI 波动的短期供给侧因素。
*   **民生/就业**：关联居民可支配收入、消费支出增速与青年失业率（16-24岁），解释消费信心不足的根源。

### 4. 投资分析：看地产拖累，看基建托底
*   **三大支柱**：
    *   **房地产**：是主要拖累项。重点关注“销售面积”（需求端）与“开发投资”（供给端）的剪刀差，以及房企到位资金来源。
    *   **基建**：是逆周期调节手段。关注水利、电力、交通等细分行业增速，分析专项债发行节奏的影响。
    *   **制造业**：是内生动力。关注高技术制造业投资是否维持高位。
*   **高频数据**：引用 30 大中城市商品房成交面积等高频数据，验证政策（如“517新政”、取消限购）的即时效果。

### 5. 进出口分析：看韧性，看抢跑
*   **总量与节奏**：分析出口同比增速，注意区分“低基数效应”和“抢出口效应”（如应对关税预期）。
*   **国别结构**：关注“东盟/一带一路”占比提升与“欧美”占比变化的对冲关系。
*   **产品结构**：重点分析“新三样”（电动车、锂电、光伏）与传统劳动密集型产品的表现。

### 6. 财政分析：看钱袋子
*   **一般公共预算**：关注税收收入（反映经济活力）与非税收入（反映地方筹资压力）的消长。
*   **政府性基金**：核心关注“国有土地使用权出让收入”（卖地收入）的下滑幅度，评估地方财政压力。

### 7. 金融数据分析：看资金活性
*   **M1 与 M2**：
    *   **M1 增速**：反映企业现金流和经营活力（主要受企业活期存款影响）。
    *   **剪刀差（M1-M2）**：负向剪刀差扩大通常意味着资金空转或定期化，企业投资意愿弱。
*   **社融与信贷**：
    *   **结构分析**：区分“企业中长期贷款”（投资意愿）、“居民短期/中长期贷款”（消费/购房意愿）与“票据融资”（银行冲量行为）。
    *   **政府债**：分析政府债券在社融增量中的支撑作用。
*   **居民资产负债表**：关注“提前还贷”现象（房贷余额下降）与“超额储蓄”（存款高增）的并存。

## 四、 写作技巧与注意事项

1.  **标题即结论**：每一页 PPT 的标题不应只写“GDP 数据”，而应提炼核心观点，例如“三季度 GDP 增速延续回落至 4.8%，名义 GDP 增速降幅收窄”。
2.  **政策关联性**：在数据分析中必须穿插政策背景。例如分析家电零售增长时，必须提及“以旧换新”政策；分析基建投资时，需提及“专项债”发行节奏。
3.  **异常值解释**：对于波动较大的数据（如进出口突增、M1 突降），需给出具体原因（如“抢出口”、“禁止手工补息”）。
4.  **对比视角**：
    *   **纵向对比**：与历史同期、上一季度对比。
    *   **横向对比**：中国与美国、欧元区的 CPI/PMI 对比。
    *   **内部对比**：国企 vs 民企利润；一线城市 vs 全国消费。
5.  **图表规范**：
    *   **组合图**：常用柱状图（增量/绝对值）+ 折线图（同比/环比增速）展示趋势。
    *   **数据标注**：关键转折点、最新数据点必须有明确的数据标签。

**附：常用术语对照**
*   **两新两重**：新型基础设施建设，新型城镇化建设；交通、水利等重大工程建设。
*   **剪刀差**：通常指 M1 与 M2 增速之差，或 PPI 与 CPI 增速之差。
*   **翘尾因素**：上年价格变动对本年的滞后影响。
*   **抢出口**：在关税落地前企业加速出货的行为。
