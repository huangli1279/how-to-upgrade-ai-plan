PPT章节：GDP 增长态势与结构分析 (GDP Analysis)

页面 1：宏观总览——全年5%目标达成，Q4增速受基数影响回落
标题：2025年GDP突破140万亿增长5.0%，四季度增速回落至4.5%但环比韧性仍存
- 总量定调：2025年全年国内生产总值（GDP）达 140.2万亿元，按不变价格计算同比增长 5.0%，圆满实现全年预期目标，“十四五”胜利收官。
- 季度走势“前高后低”： 
  - 受基数效应（去年同期政策显效抬高基数）及内需波动影响，GDP增速呈逐季回落态势：Q1 5.4% -> Q2 5.2% -> Q3 4.8% -> Q4 4.5%。
  - 环比动能：四季度GDP季调环比增长 1.2%（三季度为1.1%），显示在增量政策托底下，经济边际动能并未失速，仍保持平稳。
- 人均水平：人均GDP接近10万元人民币（约1.4万美元），稳居中等偏上收入国家行列。

页面 2：生产端拆解——服务业支撑稳健，工业受建筑业拖累放缓
标题：第三产业Q4增长5.2%发挥“稳定器”作用，第二产业因地产拖累降至3.4%
- 三产拉动分化： 
  - 第三产业（核心支撑）：四季度增加值同比增长 5.2%，全年增长5.4%，对经济增长贡献率达61.4%。其中，信息传输、软件和信息技术服务业（全年+11.1%）、租赁和商务服务业（全年+10.3%）保持双位数高增。
  - 第二产业（明显回落）：四季度增加值增速回落至 3.4%（全年4.5%）。虽然12月规上工业增加值回升至 5.2%，但受房地产开发投资深跌（全年-17.2%）影响，建筑业及上游原材料行业对第二产业形成显著拖累，导致二产增速低于整体GDP增速。
- 新质生产力动能：装备制造业（+9.2%）和高技术制造业（+9.4%）全年增速显著快于整体工业，3D打印设备（+52.5%）和新能源汽车（+25.1%）产量爆发，新旧动能转换持续深化。

页面 3：需求与贡献——外需贡献率超三成，投资端受地产拖累显著
标题：净出口Q4贡献率升至31.1%有效对冲内需缺口，资本形成贡献率仅16%
- 需求结构“供强需弱”： 
  - 外需（强支撑）：全年货物进出口增长3.8%，出口增长6.1%。四季度货物和服务净出口对经济增长的贡献率为 31.1%（全年32.7%），外贸韧性极大缓解了内需不足的压力，显示出“外需好于内需”的特征。
  - 投资（弱拖累）：四季度资本形成总额对经济增长贡献率仅为 16.0%（全年15.3%），较2024年大幅下降。全年固定资产投资下降 3.8%，主要是房地产开发投资下降 17.2% 所致，制造业投资（+0.6%）仅维持微增。
  - 消费（压舱石）：四季度最终消费支出对经济增长贡献率为 52.9%（全年52.0%）。虽然社零增速放缓（12月+0.9%），但服务消费（全年+5.5%）占比提升，主要受以旧换新政策及服务需求释放带动。

页面 4：价格与温差——名义增速持续低于实际增速，微观体感仍有寒意
标题：Q4名义GDP增速3.8%低于实际增速，GDP平减指数负增态势延续
- 名义与实际“温差”：2025年四季度实际GDP增长4.5%，而名义GDP增长 3.8%（三季度为3.7%）。名义增速持续低于实际增速，意味着 GDP平减指数 仍处于负值区间（Q4约-0.7%），虽然较三季度（-1.1%）有所收窄，但连续11个季度为负。
- 价格传导滞后： 
  - 微观体感：名义GDP增速偏低直接导致企业营收与利润改善幅度不及产出增长，尤其是第二产业名义增长仅1.9%，导致微观主体“体感温度”偏冷，企业“增产不增收”现象依然存在。
  - 通胀指标：全年CPI持平（0.0%），PPI下降2.6%。虽然年底CPI温和回升，但工业品价格通缩压力仍制约名义GDP修复。
- 政策含义：宏观数据与微观感受的背离，要求2026年政策必须在“促进物价合理回升”上持续发力，以修复名义增长。

页面 5：2026年展望——开启“十五五”新局，政策加力扭转内生紧缩
标题：2026年经济有望保持4.8%-5.0%区间，政策重心转向“扩内需”与“提质增效”
- 周期切换：2026年是“十五五”规划开局之年，中央经济工作会议定调“稳中求进、提质增效”。预计政策将加大逆周期和跨周期调节力度，重点解决“供强需弱”矛盾。
- 增长预测：市场主流机构预测2026年一季度GDP增速在 4.9% 左右，全年增速预计在 4.8% 左右。随着“两重”“两新”政策接续发力及“反内卷”成效显现，物价有望温和回升，名义GDP增速有望加快修复。
- 结构转型：经济驱动力将进一步从投资驱动向消费与创新驱动转型。预计服务业和高端制造业占比将继续提升，内需对经济的贡献度有望反弹，逐步缓解对外需的过度依赖。
